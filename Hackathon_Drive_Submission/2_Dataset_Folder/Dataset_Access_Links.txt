1. RDD2022 Multi-National Image Dataset (Tang et al., 2026; Kulambayev et al., 2026)
--------------------------------------------------------------------------------
Description: The world's largest benchmark dataset for road damage detection spanning 
47,420 high-resolution images (55,007 labeled defect instances) collected from 
6 countries: Japan, India, Czech Republic, China, United States, and Norway.
Distress Types: Longitudinal Cracks (D00, D01), Transverse Cracks (D10, D11), 
Alligator Fatigue Cracking (D20), Potholes (D40), Marking Blurs (D43, D44), Rutting (D50).
Official GitHub Repository: https://github.com/sekilab/RoadDamageDetector
IEEE Dataport DOI: https://doi.org/10.21227/5g16-v113
Academic Citation: Arya et al., Scientific Data (Nature Springer), 2024.

--------------------------------------------------------------------------------
2. Roboflow Road Defect Dataset & Kaggle Generalization Set (Zhang et al., 2026)
--------------------------------------------------------------------------------
Description: 3,755 road surface obstacle photos annotated via LabelMe for RDL-YOLO 
benchmarking, plus an independent 1,977-image generalization dataset covering bumps, 
depressions, and potholes under varying lighting conditions.
Roboflow Universe Link: https://universe.roboflow.com/project-5iscr/-sd68a
Kaggle Dataset Link: https://www.kaggle.com/datasets/anggadwisunarto/potholes-detection-yolov8
Academic Citation: Zhang et al., Scientific Reports (Nature Springer), 2026.

--------------------------------------------------------------------------------
3. PothRGBD Dataset (Prodhan & Hossain, 2026)
--------------------------------------------------------------------------------
Description: 1,000 synchronized RGB-D (Color + Aligned Depth) image pairs of real-world 
potholes collected using the Intel RealSense D415 depth camera at 640 x 480 resolution. 
Depth maps are provided in NumPy (.npy) millimeter units with RANSAC orthorectification.
Kaggle Dataset Link: https://www.kaggle.com/datasets/mahyeks/pothrgbd-rgb-and-depth-images-of-potholes
arXiv Benchmark Reference: https://arxiv.org/abs/2608.27633
Academic Citation: Prodhan & Hossain, SUNY Albany, 2026.

--------------------------------------------------------------------------------
4. Kazakhstan Road Dataset & Hybrid RDD2022 (Kulambayev et al., 2026)
--------------------------------------------------------------------------------
Description: 19,440 annotated instances across 12 distinct classes collected in urban 
and suburban environments of Almaty, Kazakhstan using vehicle-mounted cameras.
Classes: Linear cracks, grid cracks, pavement joins, patchings, fillings, potholes, 
manholes, stains, shadow, pavement markings, scratches, grid cracks in patchings.
DOI / Repository: https://doi.org/10.3389/frai.2026.1834179
Academic Citation: Kulambayev, Olzhayev & Suliman, Frontiers in Artificial Intelligence, 2026.

--------------------------------------------------------------------------------
5. Inter-Urban Dashcam Pothole Dataset (Gupta et al., 2026)
--------------------------------------------------------------------------------
Description: Real-time dashcam video recordings from inter-urban Indian highways 
converted into 2,266 frames and annotated on Roboflow for YOLOv8/YOLO11 benchmarking.
Classes: Potholes, cars, bikes, trucks, mini-trucks, information boards, pedestrians.
Roboflow Universe Link: https://app.roboflow.com/object-detection-f3m2u/potholedetection-3-wt13j/4
Academic Citation: Gupta et al., Procedia Computer Science (Elsevier), 2026.

--------------------------------------------------------------------------------
6. UAV-PDD2023 Aerial Pavement Distress Dataset (Tang et al., 2026)
--------------------------------------------------------------------------------
Description: 2,440 high-resolution aerial UAV pavement distress images spanning 
orthogonal viewpoints, complex backgrounds, and overlapping bounding box annotations.
Zenodo Open-Access Archive: https://zenodo.org/records/8429208
Academic Citation: Yan & Zhang, Data in Brief, 2023.
